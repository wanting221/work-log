# Cloud SQL 連線驅動：這裡同時裝 MySQL(PyMySQL) 跟 PostgreSQL(psycopg2-binary)
# 兩種驅動——PyMySQL 是純 Python 實作，不需要額外編譯環境，適合 Cloud Run
# 這種容器環境；psycopg2-binary 則是連 PostgreSQL 用的（例如共用其他系統
# 既有的 PostgreSQL 執行個體以節省 Cloud SQL 執行個體費用時）。
# config.py 裡的 DB_ENGINE 這個環境變數決定實際會用哪一個驅動連線，
# 兩個套件都裝著不會互相影響，也不會增加維運負擔，只是容器映像檔多幾MB。
